# Portafolio personal con Node.js

Proyecto académico desarrollado con Node.js, Express y Bootstrap.

## Requisitos

- Node.js instalado
- npm instalado

## Instalación

1. Abrir una terminal dentro de la carpeta del proyecto.
2. Ejecutar:

   npm install

3. Iniciar el servidor:

   npm start

4. Abrir en el navegador:

   http://localhost:3000

## Estructura

- `app.js`: configuración principal del servidor.
- `routes/`: contiene las rutas de la aplicación.
- `views/`: contiene las páginas HTML.
- `public/css/`: contiene los estilos.
- `public/js/`: contiene JavaScript del navegador.

## Funcionalidades

- Página principal de portafolio.
- Secciones de información personal.
- Experiencia.
- Educación.
- Habilidades.
- Proyectos.
- Formulario de contacto.
- Página de confirmación.
- Página de error 404.
- Diseño responsive con Bootstrap.
